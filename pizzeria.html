Scope & Parameters Walkthrough
In Python, function arguments are bound to parameters as local variables inside the function stack frame. All parameters and local variables vanish when the function returns.
Python Function Scope & Parameters
1. Parameters Are Local Variables
When arguments like size="large" and toppings=["pepperoni", "mushrooms"] are passed into a function call, Python binds them as brand new local variables in the function's local scope.
2. Variable Shadowing
When a local variable shares the exact same name as a global variable (e.g. local cheese = "mozzarella" vs global cheese = "parmesan"), Python uses the local one within that function. The global variable is completely untouched!
3. Scope Lifetime & Stack Frame Destruction
When the function returns, its entire stack frame is popped. All local variables and parameters are destroyed!
4. Captured vs. Uncaptured Returns
If you write my_meal = order_pizza(...), the returned pizza object is stored in memory under my_meal. If you write just order_pizza(...) without assignment, the return value has 0 references and is immediately swept by Python's Garbage Collector!
