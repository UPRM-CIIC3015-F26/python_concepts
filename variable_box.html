Python Variables & Types: Study Guide

In Python, variables act like labeled cardboard boxes that store references to objects in computer memory.

1. Division: / vs //

The single slash / is true division and always returns a float (e.g. 4 / 2 -> 2.0). The double slash // is floor division and rounds down to the nearest integer (e.g. 5 // 2 -> 2).

2. Modulo (%) and Exponent (**)

% computes the remainder after division (10 % 3 -> 1). ** raises a base to an exponent (3 ** 2 -> 9).

3. Type Casting

Functions like int(), float(), and str() convert values. int(7.9) -> 7 truncates decimals. float(5) -> 5.0 adds a decimal point.

4. Casting Errors (ValueError)

If you ask Python to convert a non-numeric string into an integer (e.g. int("apple") or int("3.14") directly), Python throws a ValueError because the conversion is invalid.

5. Boolean Conversion

0, 0.0, and empty strings "" evaluate to False. Any non-zero number or non-empty string evaluates to True.
